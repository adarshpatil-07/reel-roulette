# 🎬 Reel Roulette

**Find your next movie without endless scrolling.**

Reel Roulette is a lightweight, mood-based movie recommendation website built with HTML, CSS, and vanilla JavaScript. Choose a mood, discover a random movie, and save films to your personal watchlist.

## ✨ Features

- **Mood-Based Recommendations:** Discover movies across five moods: Mind-bending, Thriller, Comedy, Sci-Fi, and Drama.
- **Surprise Me:** Get a random recommendation from the entire movie collection.
- **Curated Movie Collection:** Explore 30 movies with their release years, genres, and descriptions.
- **Watchlist:** Save and remove movies, with data persisted using `localStorage`.
- **Copy Movie Details:** Copy a recommendation's details to share or save.
- **No Immediate Repeats:** Avoid getting the same movie twice in a row when alternatives are available.
- **Responsive UI:** Enjoy a cinematic dark theme with purple accents, smooth animations, and mobile-friendly layouts.

## 🛠️ Technologies Used

- **HTML5:** Semantic structure and accessible controls.
- **CSS3:** Responsive layouts, animations, and visual styling.
- **JavaScript (ES6+):** Movie selection, mood filtering, and watchlist interactions.
- **Web Storage API:** Persistent watchlist using `localStorage`.

## 🚀 Getting Started

### Prerequisites

A modern web browser and a code editor such as Visual Studio Code.

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/reel-roulette.git
   ```

2. Navigate to the project directory:

   ```bash
   cd reel-roulette
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in VS Code.

No dependencies, API keys, or backend setup required.
